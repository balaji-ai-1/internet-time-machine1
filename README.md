# The Internet Time Machine
Single-file site (index.html). Three.js r128 and Google Fonts load from CDN, so an internet connection is needed.

Run locally:
- Open index.html in Chrome, or
- In VS Code install "Live Server", right-click index.html -> Open with Live Server, or
- Run `npx serve .` in this folder.

Deploy: drag this folder onto app.netlify.com/drop.
